Student Result Management System - Java Project


DESCRIPTION:
  A console-based application to manage student academic
  records. Add students, enter subject-wise marks, compute
  grades automatically, search records, and export reports.

HOW TO RUN:
  1. Make sure Java JDK is installed (Java 8 or above)
  2. Open terminal in this folder
  3. Compile:  javac StudentResultManagement.java
  4. Run:      java StudentResultManagement

FEATURES:
  - Add students with roll number and name
  - Enter marks for multiple subjects
  - Auto-calculate average and letter grade
  - Search by roll number or name
  - Delete student records
  - Generate and save a Result_Report.txt
  - Data persists in students_data.csv between runs

GRADING SCALE:
  90-100  -> O  (Outstanding)
  80-89   -> A+ (Excellent)
  70-79   -> A  (Very Good)
  60-69   -> B+ (Good)
  50-59   -> B  (Average)
  40-49   -> C  (Pass)
  0-39    -> F  (Fail)

CONCEPTS USED:
  - OOP (Classes, Encapsulation)
  - Collections (ArrayList, HashMap)
  - Custom Exception Handling
  - File I/O (FileWriter, BufferedReader)
  - Iterator pattern
  - Input validation
